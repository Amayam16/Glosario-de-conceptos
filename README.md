# Glosario-de-conceptos
## Conceptos:

---

### 1.Algoritmo:
Es una secuencia de pasos finitos, ordenados y que sirve para 
realizar cualquier tipo de tarea. Ejemplo: Una receta para hacer un 
pastel.

---

### 2.Programa:
Un programa son instrucciones para que un ordenador ejecute 
tareas específicas. Ejemplo: Google Chrome que es un navegador para 
entrar a páginas de internet.

---

### 3.Código fuente: 
El código fuente es el texto con las instrucciones que 
escribe un programador usando un lenguaje de computación, organizado 
en uno o varios archivos, el cual se procesa o traduce para dar vida a uno 
o más programas de software. Ejemplo: Código fuente en lenguaje Python
nombre = "Ana"
print("Hola, " + nombre + "! Bienvenido al código fuente.")

---

### 4.Lenguaje de programación:
Un lenguaje de programación es una 
herramienta que sirve para crear programas de computadora. Permite 
diseñar e implementar el código que controla y gestiona cómo deben 
funcionar tanto el hardware como el software de un equipo. Ejemplo: 
Python, Java, C++, Javascript, etc.

---

### 5.Sintaxis: 
La sintaxis es la parte de la gramática que analiza la estructura 
de las oraciones: estudia las funciones que cumple cada palabra, las reglas 
para combinarlas correctamente y cómo deben coincidir entre sí para dar 
sentido al mensaje. Ejemplo: El sujeto que es la persona que realiza la 
acción de la oración, el verbo que es la acción que se realiza en la 
oración, los tiempos verbales, las preposiciones, la coherencia, los 
acentos, etc.

---

### 6.Variable: 
Las variables son elementos clave en cualquier investigación que 
sirven para medir y analizar información, ya que representan 
características o atributos capaces de cambiar o tomar diferentes valores.
Ejemplo: Una variable llamada edad conserve el valor de 20.

---

### 7.Constante: 
Una constante es un dato identificado por un nombre cuyo 
valor permanece fijo y prefijado, a diferencia de una variable, que es un 
dato cuyo valor sí puede modificarse mientras el programa se está 
ejecutando. Ejemplo: Φ, π, e, etc.

---

### 8.Tipo de dato:
Un tipo de dato es la categoría que define qué clase de 
información puede almacenar una variable u objeto en un programa 
informático. Es un concepto fundamental en cualquier lenguaje de 
programación (como C#, JavaScript, SQL o Visual Basic), ya que determina 
el tipo de valores que se pueden manejar y las operaciones que se pueden 
realizar con ellos. Ejemplo: El valor “Juan” es de tipo texto (string), 
mientras que 25 es de tipo número entero (integer).

---

### 9.Operador: 
Un operador es un símbolo que representa una acción 
matemática o lógica aplicada a uno o dos elementos. La mayoría de los 
operadores trabajan conectando dos términos como símbolos, textos, 
funciones o resultados previos, a excepción de los operadores de prefijo, 
los cuales actúan únicamente sobre el elemento o subexpresión que tienen 
justo a la derecha. Ejemplo: +, >=, =<, -, =, etc.

---

### 10.Expresión:
Una expresión es cualquier acto de comunicación del ser 
humano mediante el cual se exteriorizan ideas, pensamientos o 
emociones, utilizando para ello algún tipo de lenguaje verbal o no verbal.
Ejemplo: Un abrazo que comunica amor o un aplauso que demuestra una 
aprobación.

---

### 11.Condicional: 
Una condicional es una estructura de control en programación 
que permite al sistema tomar decisiones: evalúa si una regla o condición 
lógica es verdadera o falsa y, según el resultado, determina qué bloque de 
instrucciones o ruta del código debe ejecutarse. Ejemplo:
SI temperatura >= que 30° ENTONCES
MOSTRAR “Encender el ventilador”
SINO
MOSTRAR “Mantenerlo apagado”
FIN SI

---

### 12.Bucle: 
Un bucle es una construcción de programación que permite repetir 
un conjunto de instrucciones varias veces. Ejemplo: El reloj.

---

### 13.Función:
Una función es una regla que conecta un conjunto inicial con uno 
final, asignando a cada valor del primero (x) un único resultado 
correspondiente en el segundo. Ejemplo: Una máquina expendedora le 
metes un código y te entrega un refresco.

---

### 14.Parámetro:
Un parámetro es un factor o medida fija dentro de un sistema 
que sirve para categorizarlo y analizar variables como su rendimiento, 
alcance o estado. Ejemplo: En un formulario donde un apartado dice 
“Escribe tu nombre aquí:”

---

### 15.Argumento:
Es el valor concreto o dato real que se pasa a una función o 
procedimiento al momento de invocarlo, asignándose a su parámetro 
correspondiente para realizar la operación. Ejemplo: Cuando en una 
máquina metes una moneda de $10, el argumento es la moneda.

---

### 16.Retorno: 
Es el resultado o valor final que envía una función de vuelta al 
código que la llamó una vez que termina de procesar sus instrucciones.
Ejemplo: Puede ser el cambio que te regresa la máquina.

---

### 17.Arreglo: 
Es una estructura de datos ordenada que permite almacenar 
múltiples elementos o valores del mismo tipo dentro de una sola variable, 
accesible mediante un índice numérico. Ejemplo: La lista de alumnos en 
una clase.

---

### 18.Objeto: 
Es una entidad dentro de la programación orientada a objetos que 
combina datos y las acciones o comportamientos que puede realizar.
Ejemplo: Un coche que tiene propiedades como su color.

---

### 19.Método:
Es una función o conjunto de instrucciones que está asociada 
explícitamente a un objeto, determinando la acción o comportamiento 
que dicho objeto puede ejecutar. Ejemplo: Arrancar el coche.

---

### 20.Evento:
Es una acción o acontecimiento detectado por el sistema que 
desencadena la ejecución de una respuesta en el programa.  Ejemplo: Un 
clic del ratón, la presión de una tecla o la carga de una página.

---

### 21. Compilador:
Un compilador es un programa que traduce el código escrito por un 
programador (lenguaje de origen) a otro idioma informático (lenguaje de destino). Su 
función principal es convertir instrucciones de alto nivel, entendibles por los humanos, a
un lenguaje de bajo nivel (como código máquina) que la computadora pueda procesar 
directamente sin perder el sentido original del programa. Ejemplo: un traductor de libros. 
Imagina que escribes un libro en español (código fuente) y el traductor lo convierte por 
completo al chino (código máquina) para que una persona en China (la computadora) 
pueda leerlo y entenderlo perfectamente.

---

### 22. Intérprete:
Un intérprete es un programa que lee y traduce el código fuente paso a paso 
en el mismo instante en que el programa se está ejecutando, sirviendo de puente directo 
con el procesador. Ejemplo: un traductor en simultáneo: en lugar de traducir todo un libro 
antes de leerlo, escucha una frase en español y la traduce al instante al chino para que la 
computadora la entienda al momento.

---

### 23.
Depurador (Debugger): Un depurador es una herramienta que ayuda a los 
programadores a encontrar, revisar y corregir errores o fallos en un programa para 
asegurar que funcione correctamente en cualquier dispositivo. Ejemplo: un escáner de 
diagnóstico para autos: analiza el carro paso a paso para decirte exactamente qué pieza 
está fallando y dónde está el problema para que puedas arreglarlo.

---

### 24. IDE:
Un IDE (Entorno de Desarrollo Integrado) es un programa todo en uno que reúne 
las herramientas básicas para programar como editores, compiladores y depuradores en 
una sola pantalla, facilitando el trabajo y aumentando la productividad del programador.
Ejemplo: un estuche escolar completo: en lugar de buscar por separado un lápiz, una 
regla, un borrador y un sacapuntas en distintos cajones, tienes todo ordenado en un solo 
lugar listo para trabajar.

---

### 25. Editor de código:
Un editor de código es un programa especializado para escribir y 
modificar texto de programación, diseñado con herramientas que resaltan la estructura, 
organizan las líneas y ayudan a trabajar de forma rápida y sin errores. Ejemplo: un 
procesador de textos inteligente (como Word): no solo te deja escribir, sino que te subraya 
las palabras importantes en colores, te marca si te equivocas y te sugiere cómo completar 
lo que estás escribiendo.

---

### 26. Biblioteca (Library):
Una librería de programación es un conjunto de código preinstalado 
y reutilizable que resuelve problemas comunes, evitando que los desarrolladores tengan 
que escribir código desde cero y reduciendo errores, tiempos y costos. Ejemplo: una caja 
de mezcla lista para hacer pastel: en lugar de salir a cosechar el trigo y procesar el azúcar 
tú mismo, usas una base ya preparada para cocinar mucho más rápido.

---

### 27. Framework:
Un framework (o marco de trabajo) es una estructura de base prefabricada 
que incluye herramientas, reglas y librerías organizadas para que los programadores 
construyan aplicaciones de forma más rápida y estandarizada, evitando escribir el código 
básico desde cero. Ejemplo: Es como construir una casa prefabricada: en lugar de poner 
los cimientos, tuberías y vigas tú mismo, ya tienes el marco y la estructura listos; solo te 
encargas de pintar las paredes, decorar y poner los muebles como a ti te guste.

---

### 28. API: 
Una API (Interfaz de Programación de Aplicaciones) es un conjunto de reglas que 
permite a dos programas de software conectarse y comunicarse entre sí para compartir 
datos o funciones de forma segura. Ejemplo: Es como el mesero de un restaurante: tú (el 
usuario o app) no entras a la cocina a preparar la comida; le pides tu orden al mesero (la 
API), él lleva tu pedido a la cocina (el servidor) y luego te trae el platillo listo a tu mesa.

---

### 29. Repositorio:
Un repositorio (o repo) es un espacio de almacenamiento digital 
centralizado diseñado para guardar, organizar y gestionar el código fuente y los archivos de 
un proyecto de software, permitiendo rastrear el historial de cambios y facilitar el trabajo 
colaborativo en equipo. Ejemplo: Es como una carpeta compartida en Google Drive o 
Dropbox, pero con superpoderes: guarda cada versión de tus archivos, te dice quién 
cambió qué línea de código, te permite regresar en el tiempo si cometes un error y evita 
que dos personas sobrescriban el trabajo de la otra al editar al mismo tiempo.

---

### 30. Control de versiones:
Un sistema de control de versiones es un software que registra 
sistemáticamente los cambios realizados en el código fuente a lo largo del tiempo, 
guardando "instantáneas" del proyecto para poder consultar, recuperar o comparar 
cualquier versión previa cuando sea necesario. Ejemplo: Es como el historial de Ctrl + Z 
(Deshacer) infinito y organizado

---

### 31. Git:
Git es un sistema de control de versiones distribuido, lo que significa que cada 
desarrollador tiene una copia completa (un clon) de todo el proyecto y su historial en su 
propia computadora, permitiéndole trabajar sin conexión y sincronizar sus cambios con un 
servidor central cuando lo desee. Ejemplo: un documento colaborativo sin internet: cada 
persona descarga una copia exacta de todo el libro a su laptop, escribe o corrige capítulos 
enteros mientras viaja en avión, y al volver a tener señal, presiona un botón para unir sus 
cambios con la versión del resto del equipo.

---

### 32. GitHub: 
GitHub es una plataforma en la nube que reúne las herramientas y flujos de 
trabajo necesarios para crear, administrar y alojar proyectos de software en cada etapa de 
su desarrollo, facilitando la colaboración en equipo. Ejemplo: GitHub es como la red social 
y la nube para desarrolladores: el lugar público o privado donde subes tu proyecto, 
muestras tu trabajo, colaboras con otras personas y revisas el código de tu equipo.

---

### 33. Rama (Branch): 
Una rama (branch) en Git es una línea de trabajo independiente que te 
permite crear una copia paralela del proyecto para desarrollar nuevas funciones o reparar 
errores sin alterar el código principal ni interrumpir el trabajo de los demás. Ejemplo: Es 
como crear una página borrador en un cuaderno: dibujas, pruebas ideas y cometes errores 
libremente sin arruinar la hoja original. Si al final el resultado te gusta, lo pegas en el 
cuaderno definitivo; si no, simplemente descartas esa hoja sin haber dañado el trabajo 
principal.

---

### 34. Commit: 
Un commit en Git es una confirmación que registra y congela el estado exacto 
de tus archivos en un momento determinado, creando una marca en el historial a la que 
puedes regresar o consultar en cualquier momento. Ejemplo: Es exactamente como un
save point antes de una pelea contra un jefe: si entras a la batalla, cometes un error grave 
y todo sale mal, no pierdes todo tu avance; simplemente vuelves a cargar la partida desde 
la última posición segura que guardaste.

---

### 35. Merge: 
La fusión (merge) es la acción de integrar los cambios de una rama 
independiente de vuelta a la rama principal (o actual), combinando ambos historiales de 
trabajo en un solo camino unificado. Ejemplo: Es como añadir el borrador aprobado a tu 
cuaderno definitivo: tomas la página suelta donde hiciste tus cambios, la pegas en la 
sección principal del libro para que todo quede en un solo lugar y, finalmente, tiras a la 
basura la hoja borrador que ya no necesitas.

---

### 36. Callback:
Un callback es una función que se pasa como parámetro a otra función para 
que esta última la ejecute solo cuando haya terminado de realizar una tarea o cuando 
ocurra un evento específico. Ejemplo: Es como dejar tu número de teléfono en la 
recepción de un taller: en lugar de quedarte esperando horas a que reparen tu auto, le 
dices al mecánico "cuando termines, llámame". El mecánico realiza su trabajo y, solo 
cuando finaliza, utiliza tu número para avisarte.

---

### 37. Programación síncrona: 
La programación síncrona es un modelo de ejecución donde 
las tareas se realizan de forma secuencial y en orden estricto; cada instrucción debe 
finalizar por completo antes de que el sistema pueda iniciar la siguiente. Ejemplo: Es como 
hacer la fila en la caja de un supermercado: el cajero atiende a una persona a la vez, cobra 
y empaca sus productos por completo, y solo cuando esa persona se retira pasa al 
siguiente cliente. Si el cliente de adelante tarda, toda la fila se detiene a esperar.

---

### 38. Programación asíncrona: 
La programación asíncrona permite enviar operaciones lentas 
o pesadas a segundo plano para que el programa siga ejecutándose sin detenerse, 
reanudando esas tareas pendientes únicamente cuando están listas. Ejemplo: Es como 
pedir comida en un restaurante con un buzzer: haces tu pedido, te entregan el aparato y te 
vas a sentar a platicar tranquilamente mientras preparan tu plato. El programa no se 
congela esperando en la cocina; sigue haciendo otras cosas hasta que el avisador suena y 
recoges tu comida.

---

### 39. JavaScript:
JavaScript es un lenguaje de programación utilizado principalmente para 
dar interactividad, dinamismo y comportamiento a las páginas web (como animaciones, 
menús desplegables, carruseles de imágenes o mapas), funcionando tanto en el navegador 
como en el servidor. Ejemplo: Es como el sistema nervioso y muscular de una casa 
domótica: si el HTML es la estructura (las paredes) y el CSS es la decoración (la pintura y 
las cortinas), JavaScript es el mecanismo automático que hace que las luces se enciendan 
cuando entras a la habitación o las cortinas se abran al presionar un botón

---

### 40. TypeScript: 
TypeScript es un superset (superconjunto) de JavaScript, lo que significa 
que añade características avanzadas sobre el lenguaje original; debido a esto, todo código 
escrito en JavaScript es automáticamente código válido en TypeScript. Ejemplo: Es como 
un modelo de automóvil en su versión equipada: el auto base (JavaScript) incluye las 
funciones esenciales para andar, mientras que la versión full equipo (TypeScript) suma 
opciones avanzadas de seguridad y tecnología, pero manteniendo el mismo motor y chasis 
que el modelo original.
